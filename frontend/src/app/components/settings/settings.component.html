Sincronización de tareas y correos

Configura cómo y cuándo se envían automáticamente los correos a los responsables y las tareas a las plataformas conectadas (Trello, Jira, ClickUp, Azure DevOps) cuando Fireflies entrega una nueva reunión.

Envío automático de tareas y correos Flujo: cuando llega una reunión nueva vía Fireflies primero se procesa con IA (transcribe, extrae tareas y decisiones). Cuando el procesamiento termina, el admin del proyecto recibe un correo de aviso con el estado (incluido si faltan correos en tareas o participantes).

Si esta opción está activa, además, al cumplirse el tiempo definido abajo y siempre que todas las tareas tengan correo de responsable, los correos y las tareas externas (Trello, Jira, ClickUp, Azure DevOps) se envían automáticamente sin requerir confirmación manual. Si faltan correos al timeout, el sistema NO envía y avisa al admin para que complete.
Modo manual: si esta opción está inactiva, el correo y las tareas externas no salen hasta que el curador las dispare desde el detalle de la reunión. La reunión queda en el listado de Reuniones esperando acción.
