Servicios Core de la Plataforma

Fireflies AI (Transcripciones) Core

¿Cómo obtener estos datos?
  1. Inicia sesión en Fireflies.ai.
  2. Ve a Settings > Integrations > API.
  3. Copia tu Personal Access Token y pégalo aquí como API Key.
  4. Para el Webhook, copia la URL de abajo y pégala en Fireflies marcando el evento Meeting Completed.

Distribución Email (Resend API) Core

¿Cómo obtener la API Key?
  1. Inicia sesión en Resend.com.
  2. Ve a API Keys en el menú lateral.
  3. Haz clic en Create API Key, dale permisos "Full Access" y copia el código generado (empieza con re_).
  4. Asegúrate de tener un dominio verificado en Domains para poder enviar correos.

Conexión a Gestores de Tareas Externos

Azure DevOps

¿Cómo obtener tu PAT en Azure?
  1. Inicia sesión en Azure DevOps.
  2. Haz clic en el icono de User Settings (arriba a la derecha) > Personal access tokens.
  3. New Token y dale permisos de escritura (Read & Write) en Work Items.
  4. El ID del Proyecto es el nombre de tu proyecto en la URL: dev.azure.com/Organización/NombreProyecto.

Trello

¿Cómo obtener la API Key y Token?
  1. Entra a Power-Ups Admin de Trello e inicia sesión.
  2. Crea un Power-Up personalizado si no tienes uno. Copia el valor de API Key.
  3. En esa misma página, haz clic en el enlace "Token" para generar manualmente tu API Token personal.

Atlassian Jira

¿Cómo obtener tu API Token de Jira?
  1. Inicia sesión en Atlassian Security.
  2. Haz clic en Crear token de API. Dale un nombre y copia el valor generado.
  3. Ingresa tu correo asocidado a tu cuenta Atlassian, y el dominio base de tu nube (ej: empresa.atlassian.net).

ClickUp

¿Cómo obtener tu Token de ClickUp?
  1. Inicia sesión en ClickUp.
  2. Ve a Settings > Apps (en el panel inferior izquierdo).
  3. En la sección API Token, haz clic en Generate y copia el valor pk_...
  4. Opcional: Encuentra tu Team ID en la URL de tu espacio de trabajo.
