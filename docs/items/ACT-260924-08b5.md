## Historia
Como quien va a migrar los componentes viejos a los tokens de diseño, quiero poder
correr `node scripts/lint-no-hardcode.mjs`, para saber qué falta.

Hoy el comando falla antes de revisar nada cuando la carpeta del proyecto tiene un
espacio en el nombre (por ejemplo `AI Projects`): arma la ruta desde
`import.meta.url` sin decodificar el `%20` y termina con
`find: .../AI%20Projects/... No such file or directory`.

## Criterios de aceptación
### Happy path
- Dado un repositorio clonado en una ruta con espacios, cuando corro el comando,
  entonces lista los hallazgos y termina con el código de salida correcto.
### Fallo
- Dado un repositorio en una ruta sin espacios, cuando corro el comando, entonces
  sigue funcionando igual que antes.
### Borde
- Dado `--report`, entonces solo lista y sale con 0.

## Estados de UI
No aplica.

No aplica.

## Fuera de alcance
Corregir los colores quemados que el comando reporte.

## Datos y permisos
Ninguno.

## Cómo se prueba
Correr el comando desde este mismo repositorio, que está en una ruta con espacio.
